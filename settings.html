      Character identity
      
      
Appearance, personality, example dialogue, and explicit AIOS domain metadata are synchronized. Scenario and greeting text are excluded. IDs are persisted in character-card extension data when supported.

      
      
      
      
      
      
      
      
    


    

      Search character memory
      
      
      
      Search is scoped to this instance and uses substring matching. The optional model tool also requires enabled function calling and a compatible Chat Completion backend.
    


    

      Research
      
      
      
      
      

      
      
      
      

      
      
      
      
      
Discovery is exposure, not durable knowledge. Study submits sections for ingestion. Closed dossiers may not be reopened. Failed or pending research steps retain their retry ID.

    


    

      Reference resources
      
      
      
      
      
      
Imports cold reference material only. AIOS source profiles determine access; this does not grant knowledge or assert world facts. Selected file content takes precedence over pasted text. Nothing is imported automatically.

    


    

      Agent tasks & attention
      
      
      
      
      
Tasks are queued for the AIOS scheduler. Creation is not automatically retried: after a timeout, check AIOS before creating another task. Attention events wake the agent and are not dialogue or memory observations.

    


    

      Explicit runtime action
      
      
      
      
      
Move commits deterministic location state. Other choices record intent; they do not implement arbitrary inspection or item effects. Uses the latest state version and does not automatically retry conflicts or timeouts.

    


    
Diagnostics
      
      
For a copied chat that inherited another chat’s metadata. Starts a separate session and replays the retained transcript; it does not fork a historical AIOS snapshot.
